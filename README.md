# Typing Speed Test

Un test de vitesse et de précision de frappe de style "Monkey Type" développé uniquement avec les technologies web de base.

 Lancement du projet
Pour lancer l'application, il suffit d'ouvrir le fichier `index.html` directement dans n'importe quel navigateur web. Aucun serveur ou installation n'est requis.

# Fonctionnalités implémentées
- Sélection aléatoire d'un texte à reproduire au chargement.
- Zone de saisie masquée avec focus automatique pour une expérience épurée.
- Coloration des caractères en temps réel (blanc si correct, rouge avec fond si incorrect).
- Curseur clignotant sur la lettre courante à taper.
- Chronomètre se déclenchant automatiquement dès la première touche pressée.
- Calcul et affichage en temps réel du WPM (Mots Par Minute).
- Écran de résultats final affichant le WPM global, la précision et le temps total.
- Bouton de réinitialisation pour recharger une nouvelle phrase et vider les statistiques.
